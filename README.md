# Программа копирования файлов на C++

Консольное приложение, которое запрашивает у пользователя имена двух файлов: исходного и целевого. Программа читает всё содержимое исходного файла и построчно записывает его в целевой файл.

## Описание алгоритма

1. **Ввод данных:** Программа запрашивает у пользователя имена исходного и целевого файлов.
2. **Открытие файлов:** 
   - С помощью `ifstream` открывается исходный файл для чтения.
   - С помощью `ofstream` открывается (или создается) целевой файл для записи.
   - Если один из файлов не удается открыть (например, исходного файла не существует, или нет прав на запись), программа выводит ошибку и завершает работу.
3. **Чтение и запись:** В цикле `while (getline(...))` программа читает исходный файл строка за строкой. Каждая прочитанная строка сразу же записывается в целевой файл с добавлением символа переноса строки.
4. **Завершение:** После окончания файла оба потока закрываются с помощью метода `close()`.
